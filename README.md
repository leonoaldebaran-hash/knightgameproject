# Knight Game Project

Ação-aventura 3D inspirada em Ocarina of Time, com port nativo para o R36S.

Mateo, um cavaleiro de Black Waters Village, atravessa 8 templos do mundo esquecido de Gaia para resgatar Johana — reencarnação de Reia — e enfrentar Cronos.

- Documento de design: [docs/GDD.md](docs/GDD.md)
- Tecnologia: C + raylib (Web e R36S)
